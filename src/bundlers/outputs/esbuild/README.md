# Esbuild Bundle Output Archive & Provenance Documentation

## 1. Overview
This directory contains downleveled JavaScript bundle artifacts generated by **Esbuild 0.20** from the ECMAScript code samples (`es2011.js` through `es2026.js`). These artifacts serve as the reference baseline for deriving and validating AST-grep polyfill detection rules in `src/catalog/`.

## 2. Bundler Configuration & Plugin Setup
The Esbuild adapter (`src/bundlers/esbuild-adapter.ts`) leverages Esbuild's speed for module bundling while delegating ES5 AST downleveling to Babel:
- **Output Format**: `bundle: true`, `format: 'esm'`, `target: 'es2022'`, `minify: false`.
- **Downlevel Plugin**: Configures an `onLoad` plugin (`babel-downlevel`) that transforms source files using `@babel/core` and `@babel/preset-env` with `targets: { ie: '11' }`, `useBuiltIns: 'usage'`, `corejs: 3`, and `modules: false`.
- **Externalization**: Configures `external: ['core-js', 'core-js/*']`. Because Babel emits standard ES module import statements (`import "core-js/modules/...";`) when `modules: false` is set, and Esbuild treats these paths as external in an ESM bundle, top-level ESM import declarations are preserved unmodified in the output artifact.

## 3. Artifact Generation Commands
To generate or rebuild all Esbuild bundle artifacts in this directory, run from the project root:
```bash
# Generate Esbuild bundles for all samples across all target environments
node dist/bundlers/generate.js --bundlers esbuild

# Or execute TypeScript generator directly via tsx
npx tsx src/bundlers/generate.ts --bundlers esbuild --targets es5 ie11 chrome50 modern
```

## 4. Provenance Tracing & AST-grep Rule Derivation
Unlike Webpack and Rollup which emit CommonJS require calls, Esbuild's externalized ESM architecture produces static `import` statements at the head of the bundle.

### Example A: Promise (`es2015.js`)
- **Modern ES Source**: `const p = Promise.resolve(42);`
- **Esbuild ES5 Output**:
  ```javascript
  import "core-js/modules/es.promise.js";
  var p = Promise.resolve(42);
  ```
- **AST-grep Rule (`promise.yaml`)**: Matches `- pattern: import "core-js/modules/es.promise.js"`.

### Example B: Object.assign (`es2015.js`)
- **Modern ES Source**: `const clone = Object.assign({}, src);`
- **Esbuild ES5 Output**:
  ```javascript
  import "core-js/modules/es.object.assign.js";
  var clone = Object.assign({}, src);
  ```
- **AST-grep Rule (`object-assign.yaml`)**: Matches `- pattern: import "core-js/modules/es.object.assign.js"`.

### Example C: Array.prototype.at (`es2022.js`)
- **Modern ES Source**: `const first = list.at(0);`
- **Esbuild ES5 Output**:
  ```javascript
  import "core-js/modules/es.array.at.js";
  var first = list.at(0);
  ```
- **AST-grep Rule (`array-at.yaml`)**: Matches `- pattern: import "core-js/modules/es.array.at.js"`.

## 5. False Positive Prevention & Verification
For modern build targets (`<sample>_modern.js`), the `babel-downlevel` onLoad plugin is bypassed. Esbuild natively compiles the TypeScript/JS syntax directly to `es2022` ESM without emitting any `core-js` import declarations. Verifying these files with AST-grep confirms 0 false positives.
